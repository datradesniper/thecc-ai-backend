## How to use this workbook

Print it, or copy each table into your journal. Complete one page per session. **Nothing in this workbook asks you to take a trade.** It asks you to describe what you see and to name where an idea would be wrong — which is the skill the course is actually teaching.

⚠️ If you cannot fill in the *invalidation* column, the observation is incomplete. Leave it blank and move on rather than inventing one.

## Certification readiness check

Tick honestly. All eight before attempting the quiz.

- [ ] I can state the middle-bar close rule without looking.
- [ ] I can explain why higher sensitivity means more zones.
- [ ] I can read the balance percentage correctly.
- [ ] I can state the difference between MSS and BOS in one sentence each.
- [ ] I can explain why equal levels arrive late and why that is preferable.
- [ ] I can define a buy-side sweep and say which direction it favours.
- [ ] I can recite the seven-step sequence in order.
- [ ] I can explain why size is decided last.
