How to use this workbook

Print it, or copy each table into your journal. Complete one page per session. Nothing in this workbook asks you to take a trade. It asks you to describe what you see and to name where an idea would be wrong — which is the skill the course is actually teaching.

⚠️ If you cannot fill in the invalidation column, the observation is incomplete. Leave it blank and move on rather than inventing one.
